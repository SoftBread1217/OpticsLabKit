# 第一次使用

目标：把两条光学实验曲线画到一起，并留下可复现的处理记录。

1. 运行 `python -m opticslabkit serve`，打开 http://127.0.0.1:8766。
2. 点“先体验 TE / TM 示例”。当前显示的是合成光谱。
3. 选择“Min-Max → [0, 1]”，观察峰高一致后两条曲线的峰位和形状差异。
4. 将移动平均改为 5 或 9 点，观察细小振荡如何变化。回到 1 点查看原始细节。
5. 点“下载结果 ZIP”，解压查看图片、处理后 CSV 和 `manifest.json`。
6. 选择自己的 TXT、CSV 或 XLSX 文件，选择横坐标列和需要比较的纵坐标列。

当前电脑已配置好项目环境。下次使用可直接双击项目目录里的 `start.cmd`，
保留打开的终端窗口，再访问上面的本地地址。关闭终端会停止服务。

对仪器导出的文件，先检查原文件：表头上方有几行仪器信息，就填相应“跳过前几行”；
只有数值、没有列名时选“没有表头”。程序会生成 Column 1、Column 2 等列名。
XLSX 文件导入后可选择工作表。更改分隔符、表头、跳过行数后需重新选择文件。

每条曲线独立去除 X 或 Y 缺失/非数值的行，不会替换为零。
所有处理参数应用于当前选中的全部曲线。曲线按原始采集顺序绘制，
往返扫描、滞回与重复横坐标不自动合并或排序。

结果包中的文件：

| 文件 | 用途 |
| --- | --- |
| figure.png | 300 dpi 图片，便于放进报告和 PPT |
| figure.svg | 矢量图片，可继续排版；中文显示取决于查看器字体 |
| curve_01.csv 等 | 有效采样点的原始值、基线、处理值和原表行序号 |
| manifest.json | 原文件哈希、读取选项、处理参数、软件版本、提示和结果统计 |

导出前检查轴名称和单位。线性功率、百分比、dB、场振幅具有不同含义，需要根据
实验确认。此版本不会自动推断测量量，不会自动计算消光比或半高宽。
原始文件始终保持不变。个人实验数据放在 `local_data/` 中，它默认被 Git 忽略。
