# v0.3.0：同一组测量，灵活对照

本版不替代 Origin。它解决的是整理数据、控制处理差异、保存对照方案，再继续精修。

启动：配置好依赖后双击项目根目录 `start.cmd`，打开 http://127.0.0.1:8766。
升级后需要重新启动旧服务；单纯刷新不会更新已载入的后端模块。

## 同时看上扫和下扫

1. 点“往返扫描示例”（合成数据，不是论文测量）。
2. 第一条曲线选“分支 1 ↑”，把图例名称改成 `Ascending X`。
3. 点“复制为另一个分支 / 处理对照”。第二个视图选“分支 2 ↓”，改名 `Descending X`。
4. 给两个视图选择不同线型。现在同一张图能比较两条路径，而不需重复导入文件。
5. 下载结果 ZIP：两个 CSV 记录各自的原表行号和方向，Origin 表保留各自的 X/Y 列。

方向只表示 X 增减，不自动证明扫描时间或器件状态；转折点共享。
复制的是视图，不是新的实验，不会被当作独立重复测量。图中同时含往返分支时，
重复测量汇总仍拒绝混合方向。

## 一条处理，另一条不动

1. 在一个视图勾选“独立处理”，设置基线、平滑和归一化。
2. 另一个保持跟随左侧共享设置。修改左侧窗口，独立视图的窗口不会被改写。
3. 取消“独立处理”会重新跟随共享参数。
4. 结果表显示共享/独立及有效窗口；导出 manifest 记录完整有效参数。

请不要把独立归一化后的曲线和原始强度当成同尺度比较。
重复测量只有归一化、基线、平滑一致时才能汇总；即便程序允许，条件和独立性仍需你确认。
SD 是样本标准差，不是 SEM 或置信区间。

## 仪器文件读错了，不必重选

调整左上“读取设置”中的跳过行数、表头、分隔符、小数符号，然后点对应文件的
“按上方读取设置重新读取”。使用的仍是原始文件字节，不会覆盖硬盘上的文件。

失败时旧数据保留；成功后分组、图例、样式、对照视图、分支和独立设置会重置，
请重新检查选列与图样。共享处理参数仍保留。如果窗口不适用于往返扫描，
程序先给出分支选项，你可以选单个分支继续操作，而不会卡在无法选择分支的状态。

## 保存、恢复与清理

“保存会话”保留原始文件、所有视图、独立设置和共享默认值，重启后可恢复。
v0.2.0 会话仍能读取；新 schema-2 会话不能交给旧版程序打开。
会话包含实验原始数据，分享前检查；结果 ZIP 也包含处理后数据。

移除文件只清理本机服务里的数据副本，不删除原始文件。载入新示例或会话会原子替换
当前窗口使用的数据，失败不会先丢弃旧数据；其他窗口的独立数据不被清理。
未保存的当前对照在成功载入示例/会话后会被替换，重要工作请先保存。

## 验证范围

回归测试覆盖后端、旧会话、复制视图、独立参数与前端事件/模型和真实本机接口联动。
前端事件测试使用模拟 DOM，不是浏览器视觉或原生文件选择器验收。
请亲自在浏览器试一次保存后打开，并用仪器数据检查分支与单位；程序不会自动拟合
峰位/半高宽/消光比，也不会保证期刊合规。
