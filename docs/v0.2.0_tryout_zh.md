# v0.2.0：十分钟体验

定位：光学数据整理与可复现出图，不替代 Origin 的高级拟合与精细排版。

## 1. 看出图改进

双击项目根目录的 `start.cmd`，保留启动窗口，打开 http://127.0.0.1:8766。
如果工作台已在运行，刷新页面即可；后端升级后需要关闭旧服务再重新启动。

点 **TE / TM 示例**，展开左侧 **科研图样：尺寸、字体与坐标**：

1. 切换单栏 85 × 65 mm，看看字体和线宽相对图尺寸的效果。
2. 清空图片标题（很多论文把说明放在图注），按目标期刊填写尺寸和字号。
3. 在右侧“光学分组与曲线样式”将 TM 设为虚线、TE 设为实线，修改图例名称。
4. 调整图例位置、轴范围。上下限要同时填，留空则自动。对数轴不接受零或负数。
5. 下载结果 ZIP，对比 `figure.svg`：它与页面预览是同一份图样。

SVG 保留文本，可在支持 SVG 的矢量编辑器里改字和排版；这不等于可在 Origin
恢复一张关联原数据的图。字体依赖打开文件的电脑；PDF 嵌入字体用于稳定交付。
PNG 适合报告，SVG/PDF 适合矢量排版。科研质量仍取决于数据、单位、标注和目标期刊要求。

## 2. 看光学实验流程

点 **往返扫描示例**：初始按采集顺序显示完整轨迹。
在曲线卡片选择 **分支 1 ↑** 或 **分支 2 ↓**，检查点数和不同路径。
方向只根据 X 增減，不自动判断物理状态或时间顺序。转折点会共享；平台保留。
实际数据里很小的 X 反转也会生成分支，请核对仪器扫描方式。
对整条往返轨迹使用移动平均会报明确错误，需要先选分支，避免跨转折点平滑。

点 **重复测量示例**：三条同条件 TE 合成曲线加上均值和 SD 阴影。
示例单位、条件和独立运行是已知的，所以示例自动勾选确认项；自己的实验需你确认。
取消“单位、条件、独立重复”确认，汇总会停止，但单条曲线仍可查看。
重复测量按 **组名 + 偏振** 汇总，单调且无重复 X，方向也必须一致。
不同网格只在共同区间内插值到首条曲线采样点，不在两端外推。

阴影是样本标准差 SD（`ddof=1`），不是均值标准误 SEM 或置信区间。
点数是网格点数，n 是测量条数。同一文件、同一列、同一分支选两次不会算作两次独立测量。
归一化会改变幅值和误差解释，不能把独立归一化后的 SD 当成原始强度误差。

自己的 TE/TM 文件导入后，核对偏振标记，并给相同条件的曲线填写相同组名。
配对表只检查每组 TE/TM 条数是否唯一，不证明物理条件相同，也不会算消光比。

## 3. 继续编辑，而不是重新开始

点 **保存会话** 下载 `comparison.olksession.json`。它包含原始文件字节、工作表、
读取设置、选列、图例、偏振、组名、分支和图样。重启服务后点 **打开会话** 恢复。
Excel 会话恢复后仍能切换工作表。保存上限是原始文件合计 20 MB；会话 JSON ≤ 29 MB。
会话文件会包含你的实验数据，分享前要检查；不要把个人会话提交到公开仓库。

结果 ZIP 不包含原始文件，包括：

| 文件 | 怎么用 |
| --- | --- |
| figure.png / .svg / .pdf | 同一图样的位图和矢量图 |
| origin_xy.csv | Origin 导入后将 X_01/Y_01、X_02/Y_02 分别设为 X/Y；空白是缺失，不是零 |
| curve_01.csv 等 | 每条曲线有效行、原始 Y、基线和处理 Y；保持各自网格与顺序 |
| repeat_01.csv 等（有汇总时） | X、mean、sd、n，SD 用作 Y 误差列需在 Origin 明确指定 |
| manifest.json | 来源哈希、参数、分组、图样、软件版本和统计方法 |
| redraw.py + plot_style.py | 修改 manifest 的 figure/style 后运行 `python redraw.py`，重新生成图 |

重画脚本需要 Python、Matplotlib 和 pandas，不需要安装 OpticsLabKit。
脚本以自身所在目录找数据，拒绝覆盖已有的 `redrawn.*` 文件。字体和软件版本不同可能影响排版。
原始测量文件不会被修改。当前处理参数仍统一作用于选中的全部曲线。

## 建议你反馈这三件事

- 用论文实际单栏宽度导出后，字是否能看清，线型和图例是否合适？
- 你的仪器扫描文件能否正确分出分支，是否需要手工指定分支边界？
- Origin 导入表、保存后恢复会话，哪个环节还有重复操作？
