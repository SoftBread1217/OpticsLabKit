# OpticsLabKit v0.1.0

The first public version of OpticsLabKit is a local optical experiment data workbench.
Import instrument data, choose columns, compare curves, apply explicit processing,
and export figures with enough metadata to repeat the workflow.

## Included

- Chinese browser interface running on `http://127.0.0.1:8766`.
- TXT, CSV, TSV, DAT, and XLSX import with worksheet and parsing controls.
- Multiple Y columns and files in the same comparison.
- Optional baseline subtraction, point-based moving averages, and normalization.
- Preserved acquisition order for descending and returning scans.
- 300 dpi PNG, SVG, processed CSV, and source/parameter manifest in a downloadable ZIP.
- Python API, CLI, Windows launchers, and a deterministic synthetic TE/TM example.

## Install and try

Download the wheel from the release assets, then run:

```bash
python -m pip install opticslabkit-0.1.0-py3-none-any.whl
python -m opticslabkit serve
```

Open the local address and click **先体验 TE / TM 示例**. The example contains synthetic
data; no private experimental files are included. Full instructions and source-install
steps are in the repository README and Chinese guide.

## Validation and limits

21 tests cover text encodings, separators, headers, XLSX sheet selection, invalid-data
filtering, scan order, processing calculations, exports, and local HTTP behavior.
The result ZIP was downloaded through the browser and its image/data entries checked.

Units must be supplied by the user. Normalizing curves separately removes absolute
intensity ratios. Sample maxima are not fitted peaks or FWHM. This release supports
XLSX rather than legacy XLS files; it does not control laboratory instruments.
