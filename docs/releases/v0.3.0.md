# OpticsLabKit v0.3.0 — 独立处理、分支对照与可恢复导入

这一版集中改善真实数据工作流：同一条测量可以同时展示多个分支或处理方案，
不需要反复导入，也不再只能给所有曲线套一份参数。

## 更新

- **逐视图独立处理**：在共享默认设置上，单独配置某个视图的基线、平滑、归一化。
  结果表与导出记录实际生效的参数。
- **同一测量，多种对照**：复制视图后分别选择上扫/下扫、处理/未处理，支持同图比较。
  复制不是独立实验，最多同时比较 12 个视图。
- **无需重选文件的重读**：修改仪器读取设置后从原始字节重读，失败保留旧数据。
  成功会重置分组、样式、视图和独立设置，请核对选列。
- **分支恢复操作**：分支检测不依赖平滑设置，即使当前窗口不适用于完整往返扫描，
  仍可先选分支继续处理。
- **统计更谨慎**：不同归一化尺度会提示；重复测量的处理方法不一致时拒绝 mean/SD。
- **会话升级与内存清理**：schema 2 保存多视图和独立参数，继续读取 v0.2.0 会话。
  移除文件释放内存；载入示例或会话原子替换当前数据，原始磁盘文件不会被删除。
- **前端回归测试**：模拟 DOM 事件/模型与真实本机 API 联动；CI 同时检查 JavaScript。
- **升级提示**：发现前端已升级而旧服务仍在运行时，会明确提示保存旧页面会话、重启服务。

PNG / 可编辑文本 SVG / PDF / Origin X-Y 表 / 独立重画脚本仍受支持。

## 安装与体验

下载本 Release 的 wheel，然后：

```bash
python -m pip install --upgrade opticslabkit-0.3.0-py3-none-any.whl
python -m opticslabkit serve
```

打开 http://127.0.0.1:8766。源码安装用户执行 `python -m pip install -e .`，
然后重启服务。Windows 可双击项目目录的 `start.cmd`（需先安装 Python 和依赖）。

先点“往返扫描示例”，选上扫分支，再复制一个视图选下扫，看看两条路径。
[v0.3.0 体验指南](https://github.com/SoftBread1217/OpticsLabKit/blob/v0.3.0/docs/v0.3.0_tryout_zh.md)

## 使用边界

- 旧 schema-1 会话可读取；新 schema-2 文件不能在旧版程序中打开。
- 会话含原始数据，结果 ZIP 含处理后的数据；分享前检查数据权限。发布包不含个人实验数据。
- 共享/独立设置都不会改写原文件。混合方向、重复 X 或不同处理方法不会直接计算重复 SD。
- 不计算拟合峰位、半高宽或消光比，不猜单位，不保证期刊图样合规。
- 前端事件测试不等于浏览器布局/原生文件选择器测试；请在自己的浏览器进行一次恢复体验。
