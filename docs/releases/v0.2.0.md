# OpticsLabKit v0.2.0 — 从光学实验到可复现的图

这一版聚焦光学数据整理与后续编辑，不替代 Origin 的高级拟合和精细排版。

## 主要更新

- **统一科研图样**：预览与 PNG/SVG/PDF 使用同一绘图引擎。可调整毫米尺寸、
  字号、字体、坐标范围与对数轴、图例、逐曲线颜色、线型和标记。
  SVG 保留文本，PDF 嵌入字体；单/双栏预设只是参考，请按目标期刊核对。
- **光学实验流程**：显式 TE/TM 偏振与实验条件分组、配对数量检查、
  按 X 增减检测扫描分支。分支选择在处理之前，原数据不排序、不覆盖，
  整条往返扫描跨转折点平滑会被拒绝。
- **重复测量汇总**：确认同单位、同条件且独立测量后，按同组/同偏振生成均值
  与样本 SD。只允许同方向、无重复 X 的单调分支；只在共同区间内插值，绝不外推。
  SD 使用 `ddof=1`，不是 SEM 或置信区间。
- **可恢复、可重画**：`.olksession.json` 保存原始文件、读取选项、选列、分组、
  样式与处理参数。`origin_xy.csv` 保留每条曲线的独立 X/Y 网格；
  `redraw.py` 和 `plot_style.py` 可脱离 OpticsLabKit 重画图片。
- **三个合成示例**：TE/TM、往返扫描、重复测量，均不是论文实验数据。

## 安装与启动

从本 Release 下载 wheel，在 Python 3.10 或更新版本中运行：

```bash
python -m pip install opticslabkit-0.2.0-py3-none-any.whl
python -m opticslabkit serve
```

打开 http://127.0.0.1:8766。源码用户可运行 `python -m pip install -e .`；
Windows 配置好依赖后可双击项目根目录的 `start.cmd`。

解压结果 ZIP，将 `origin_xy.csv` 导入 Origin，分别把 X_01/Y_01 等列设为 X/Y。
重画脚本需要 Matplotlib 和 pandas，拒绝覆盖已有 `redrawn.*` 文件。

## 边界与数据安全

- 不自动计算 FWHM、拟合峰位、消光比，不猜测或转换物理单位。
- 独立归一化会丢失绝对强度比例；其 SD 不代表原始幅值测量误差。
- TE/TM 配对只检查显式分组中的条数，不证明实验条件相同。
- 处理参数仍统一作用于当前全部曲线，分支与样式则逐曲线选择。
- 保存会话**包含原始数据**，分享前请检查。结果 ZIP 不含原始文件，
  但含处理后的数据。原始文件永远不被改写，发布包只含代码和合成示例。
- 会话原始文件合计上限 20 MB；本地服务不向第三方上传测量数据。
- 浏览器文件选择器的自动验收曾受权限检查超时影响；会话恢复接口及跨服务
  重载已通过测试。请在自己的浏览器里体验一次保存后重新打开。
